# Fictional six-fact example

Every name, label, device and relationship in this example is invented. It supplies 72 training questions, 12 development questions, a sealed 36-question heldout set, 18 unrelated controls, and 12 near misses.

Question variations are authored from templates. The fixture exercises direct and reverse relationships within the explicit Linden scope. It is a runnable example with a pending Spark score. It does not carry the source experiment's facts, captures, weights, or accuracy claim.

Keep your own facts, lesson files, and run outputs outside source control. A trained memory can encode those facts even when they are absent from its filename.
